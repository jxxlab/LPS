# Logic:
# 1. Convert each sample's barcode-level files into an individual loom file and merge into one combined loom file.
# 2. Read the corresponding RDS file and convert the annotated Seurat object into an H5AD file, preserving cell metadata and dimensionality reductions.
# 3. Match cells between the combined loom file and the H5AD file using cell barcodes, ensuring that cell identifiers are consistent.
# 4. Run scVelo preprocessing, calculate neighbors and moments, estimate RNA velocity, and construct the velocity graph.
# 5. Preserve the original Figure color mapping and visualize velocity on the corresponding UMAP embedding.
